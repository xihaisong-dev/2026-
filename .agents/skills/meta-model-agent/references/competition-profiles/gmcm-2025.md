# GMCM / NPGMCM 2025 竞赛规则摘录

本 profile 对应 2025 年“华为杯”第二十二届中国研究生数学建模竞赛。目标竞赛的当期官方通知和标准文档优先于本文件。

## 机器约束

- `gmcm` 是机器键；`npgmcm`、`huawei`、`华为杯` 和 `研究生数学建模` 是可接受别名。
- 赛题导入必须同时提供赛题原件和官方论文模板。模板应通过 `scripts/problem_intake.py --template` 导入，保存在工作区的 `题目/官方论文模板/`，不能用 skill 自带模板替代上传凭证。
- 支持 LaTeX 和 Word 两种撰写路线，最终均应按当届要求导出 PDF 提交。DOCX 路线必须上传 `.doc` 或 `.docx` 官方模板并以其作为底稿；内置 Markdown 只是内容骨架，不能替代官方格式。旧 `.doc` 可由 LibreOffice 或 Windows Microsoft Word 转换；LibreOffice 可自动生成 PDF 预览，仅有 Word 时手动另存 PDF并通过 `--preview-pdf` 登记。
- 最终 PDF 使用官方封面；学校、队伍和队员信息仅允许出现在封面，摘要页、目录页、正文和附录保持匿名。
- 摘要页从页码 1 开始，摘要不超过两页；正文无页眉，页码位于页脚中部并连续编排。
- 论文必须包含目录，目录最多展开到三级（`section`、`subsection`、`subsubsection`）；禁止使用四级目录（`paragraph` 或 `subparagraph`）。子问题章节不能只有一个笼统标题，应至少用二级标题在目录中展示建模、求解、结果和检验等内部结构；有实际独立论证内容时建议继续展开三级标题。
- 题目使用三号黑体，一级标题使用四号黑体并居中，正文汉字使用小四号宋体，行距按官方模板执行。
- 正文必须包含正文引用和按引用顺序排列的参考文献；程序和人工智能工具输出也要注明来源。
- AI 使用说明不是本 2025 摘录推导出的无条件附录。每次上传赛题时必须手动声明 `required` 或 `off`；选择 `required` 时启用附录“AI 使用说明报告”，并如实记录工具、版本、用途、关键交互、采纳和人工修改情况。
- `required` 还要求填写 `论文/AI使用记录.json` 并引用本地证据文件。机器只校验报告、结构化记录和证据引用是否完整且一致，不证明记录真实。
- 正文 30 页是本项目内部质量目标，不是从 2025 官方材料推导出的最低页数。标准模式低于目标给出告警，冠军模式按实际编译或预览页数硬性拦截；不得用空泛内容或放大版式凑页。
