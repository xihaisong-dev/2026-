# GitHub 设置与启用状态

模板文件随仓库提交；访问权限和分支保护是服务器设置，文件本身不会开启这些设置。

| 项目 | 当前状态 | 后续操作 |
| --- | --- | --- |
| 成员、任务、交接和 PR 模板 | 已建立 | 四人按模板填写 |
| Repository checks 工作流文件 | 已建立，远端运行待核验 | 检查 Actions 页面 |
| 四人账号与角色绑定 | 待确认 | 补齐 TEAM.md |
| 协作者邀请 | 未执行 | 所有者确认账号后邀请 |
| main 分支保护 / Ruleset | 未配置 | 所有者按需启用 |
| CODEOWNERS 自动审阅映射 | 未配置 | 账号确定后创建有效映射 |

建议所有者在 Settings 确认可见性、成员访问和 main 合并规则。各用自己的账号与令牌，成员使用协作所需的写权限。分支规则可要求 PR、至少一名非作者批准、讨论已解决、Repository checks 成功，并限制删除和强推；实际可用选项以当前仓库界面为准。

规则未启用前，GitHub 不会自动阻止违反文档约定的操作。正式使用前按当届要求核对资料可见性、协作范围，记录进 rules.json。
