# 固定技能使用和升级

唯一入口：[meta-model-agent](../.agents/skills/meta-model-agent/SKILL.md)。源版本、排除项、逐文件哈希记录在技能版本锁.json。

运行只需仓库内 mm.py；普通任务不要修改 .agents 下的源快照。工具/、参考资料/、模板/ 中资源由初始化和阶段 begin 同步，这是同一版本的运行副本，不是第二套工作流。

升级由 O 建任务：确定完整上游版本 → 核对本地差异和兼容性 → 替换快照与锁 → 在临时工作区初始化并测试关键阻断/推进行为 → 明确现有状态迁移策略 → 审阅合并。不得在正式状态上用 init --force 试验。
