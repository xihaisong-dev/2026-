# 2026 华为杯三人协作仓库

三位真人分别操作 A、B、C 三个 Agent。A 负责分析、建模、编程、求解与全文整合；B 逐问写作；C 审查章节格式并反馈 B。每完成一问就交接，不自动创建或启动队友的 Agent。具体见 [正赛协作协议](协作/正赛Agent协作协议.md) 和 [三人分工](协作/分工.md)。

仓库统一使用固定的 `meta-model-agent` 完整版，入口为 `.agents/skills/meta-model-agent/`，来源和本地 2026 适配补丁见 [技能版本锁](协作/技能版本锁.json)。三端使用同一仓库版本，不依赖各自安装的个人 skill。

当前为赛前准备：`gmcm / PDF / baseline / standard`，DISCOVERY 尚未启动；正式题面和官方模板仍须按 intake 导入，AI 报告选择仍为 pending。已有模板试编译及 Word 版式检查，不代表研究阶段或参赛论文验收。

## 三端如何交接

1. 三人各自独立 clone/worktree，填写 [分工](协作/分工.md)，阅读 [协作指南](CONTRIBUTING.md)。A/B/C 是工作端，不是远端分支名称。
2. A 完成一问并核验结果，填写 [A 给 B 的交接](协作/交接/Q1/A给B的写作交接.md)。由 B 操作者在自己的 Agent 中启动写作。
3. B 交付章节和预览，填写 [B 给 C 的交接](协作/交接/Q1/B给C的审查交接.md)。C 按 [章节审查模板](审查/章节格式/TEMPLATE.md) 反馈，B 填写 [修订回复](协作/交接/Q1/B的修订回复.md)，再由 C 复查。
4. A 审核全部有效章节，统一全文、引用和附录，最后撰写摘要并编译检查。见 [全文审核入口](审查/全文审核/README.md)。

Q1 目录中的文件均为空白示例，不代表问题一已经求解或交接。实际题目有几问就建立几个对应目录；每次交接绑定版本和证据。任务进度以 Issue 为准，交接和审查记录保存成果与接收结论，不另建重复看板。

## 目录与责任

| 路径 | 存放内容 | 主责 |
| --- | --- | --- |
| 题目/ | 原始题面、官方模板、导入清单 | A |
| 用户数据/ | 未修改的原始附件与数据 | A |
| 数据/processed/ | 规范模型输入；默认不随 Git 同步，须给再生成命令或共享位置与哈希 | A |
| 问题分析.md、建模报告.md | 正式题意与模型，按阶段生成 | A |
| 程序/、计算结果.md | 求解代码、参数和计算报告 | A |
| 图表/ | 全部结果.json、图表、源数据与独立运行记录 | A；B 引用 |
| 论文/章节/ | 每问正文，文件名由 A 派稿确定 | B 写作，C 审查，A 集成 |
| 论文/ | 正式论文入口、文献、附录和最终 PDF | A |
| 协作/交接/QN/ | 逐问交付、版本和修订回复 | 各交付端；接收端本人确认 |
| 协作/赛前研读/、协作/写作核对/ | 长期研读材料、官方文件存档、写作检查工具 | A 维护；三端使用 |
| 审查/章节格式/QN/、审查/全文审核/ | C 逐问意见、复查及 A 全文审核 | C / A |
| output/ | 赛前模板、模块及演示预览，不是正式提交目录 | A |
| 状态/、日志/ | 唯一阶段状态与事件记录 | A 端统筹责任人串行维护 |
| 当前任务/执行中/ | 阶段工具生成的临时任务资源 | 工具管理 |
| 工具/、参考资料/、模板/ | 技能运行资源与派生副本 | 工具管理 |
| .agents/skills/meta-model-agent/ | 固定技能源及补丁；普通写作不修改 | A 统筹维护 |

`参考资料/`、`模板/` 和 `当前任务/执行中/` 会在阶段 begin 时重建；`工具/` 中同名文件可能被同步覆盖。不要把唯一的手工资料放在这些目录。正式稿写入 `论文/`，持久研读与交接放 `协作/`，项目自有脚本放 `协作/工具/`。不要在 A/B/C 各建一份正式代码、结果或论文。

## 工作流与检查

`DISCOVERY → FORMULATION → COMPUTATION → EVIDENCE → SCHEMATICS → MANUSCRIPT → ASSURANCE`

正式阶段只通过工具推进，不能用勾选清单代替门禁。B 可先写逐问草稿，正式 MANUSCRIPT 时须绑定当时有效的求解证据。O/M/E/W 仅作为历史职责术语兼容，不代表另有四人。

```bash
python mm.py stage current
python mm.py pipeline overview
python 协作/工具/check_repository.py
python 协作/工具/verify_migration.py
python 协作/工具/verify_template_2026.py
```
