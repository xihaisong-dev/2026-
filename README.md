# 2026 华为杯数学建模协作仓库

四位协作者共用的资料、模型、程序、论文和交接记录。当前为赛前初始化，尚未录入赛题、数据和当届官方规则；目录建好不代表比赛验收通过。

## 从这里开始

1. 阅读 [分工表](00_admin/TEAM.md)，填写 GitHub 用户名。
2. 按 [协作指南](CONTRIBUTING.md) 独立克隆、领取任务、创建分支。
3. 下班、换负责人或提交阶段成果时，填写 [交接单](00_admin/handoffs/TEMPLATE.md)。
4. 接手前看 [当前待办](todo.md)、相关 Issue、最近交接单和 [决策记录](00_admin/DECISIONS.md)。

## 每次协作的最短流程

**Issue 明确任务 → 一人负责一个任务分支 → 小步提交 → PR + 交接单 → 接收人检查 → 统筹合并。**

任务唯一编号采用 GitHub Issue 编号；未启用 Issues 时用 `LOCAL-日期-角色-序号`，见 [任务规则](00_admin/TASKS.md)。禁止两人同时写同一物理目录，禁止直接在 main 上日常开发。

阶段状态以 [workflow.json](00_admin/workflow.json) 为准，任务状态以 Issue 为准，交接状态以对应交接单为准。三者用途不同，不重复维护一套任务表。

中文论文暂按 LaTeX 预设，队员可在开赛前共同改为 Typst；尚未选择正式模板。四个仓库协作角色不表示已确认正式参赛人数或参赛资格，相关信息待按当届通知录入。

仓库访问邀请、分支保护等启用情况见 [GitHub 设置清单](00_admin/GITHUB_SETUP.md)。
